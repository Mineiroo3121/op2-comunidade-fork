# Ordem Paranormal 2 Edição — comunidade

Sistema comunitário independente para Ordem Paranormal 2ª Edição no FoundryVTT, com o objetivo de facilitar a vida de todos os mestres de Ordem 2E.

Este é um fork comunitário independente para Foundry VTT, baseado no trabalho original de Sérgio Sousa. O projeto reúne funcionalidades de ficha, habilidades, vocações, ferramentas e recursos relacionados às missões, além de opções Homebrew.

## Recursos em destaque

- Habilidades e vocações disponíveis no sistema.
- Recursos e funcionalidades relacionados às quatro missões oficiais.
- Aparência da ficha personalizável por afinidade. A escolha é exclusivamente estética nesta versão e não altera regras ou poderes paranormais.
- Suporte a conteúdo Homebrew.

## Instalação

A instalação recomendada é pelo manifesto publicado na página de Releases. Para instalação manual, extraia o pacote na pasta `Data/systems/op2-comunidade-fork/`, mantendo `system.json` diretamente dentro dela.
